# Tuubaamon

Ein Monster-Sammelspiel als Fan-Art für den Animator Tuubaa. Die Monster sind Mitgliedern der Community nachempfunden,
die Kämpfe funktionieren wie bei Paper Mario / Mario & Luigi (Timing-Treffer). Grafikstil: **2.5D** (3D-Welt mit 2D-Figuren),
Kämpfe aus einer erhöhten Seitenperspektive.

- Engine: Godot 4.7 (Forward+)
- Start: `Szene/main menue/main_menue.tscn`
- Debug-Kampf: `Szene/DEBUg/debug_battlefield.tscn` (mit F6 starten)
